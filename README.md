# 可可拦截工具 (Keke AdBlock)

一个基于 [DNS66](https://github.com/julian-klode/dns66) 二次开发的 **安卓 DNS 广告拦截工具**。无需 Root、无需联网授权，通过本地 VPN 通道拦截广告与追踪请求，守护你的网络纯净。

> 本项目遵守 **GPL-3.0 开源协议**，源码基于 julian-klode/dns66 修改而来，并已保留原作者的版权声明。

---

## 📱 这是什么？有什么用？

手机上网时，广告、追踪器、恶意跳转常常偷偷加载，浪费流量、拖慢网速、还可能泄露隐私。**可可拦截工具** 在本地建一条 VPN 通道，把 DNS 查询接管过来，凡是命中黑名单的广告域名，直接拒绝解析——广告还没到你就被拦下了，干净、快速、不打扰。

### 核心价值
- ✅ **免 Root**：普通用户也能用，不需要刷机、不需要解锁
- ✅ **全应用生效**：浏览器、游戏、视频、社交……所有 APP 的广告都能拦
- ✅ **隐私保护**：本地处理，数据不上传、不联网验证，纯本地黑名单
- ✅ **不耗电**：轻量拦截，对老手机也很友好

## 🔍 工作原理（DNS 层 + IP 层）

**免 Root 的秘密：VPN 通道。** 可可拦截工具通过 Android 的 `VpnService` 在本地建一条虚拟通道，把系统的 DNS 查询接管进来，命中黑名单的域名就地处理掉——不修改系统、不需要 Root。

- **DNS 层（DNS 拦截模式）**：接管 DNS 查询，命中黑名单 → 返回**空解析（NXDOMAIN）**，域名解析失败，广告自然加载不出来。
- **IP 层（规则拦截模式）**：命中黑名单 → 返回**黑洞地址 `0.0.0.0`**，连接在 IP 层直接被拒绝，比 DNS 层更快更彻底。

> 只拦"命中规则的广告/追踪域名"，正常网站、扫码支付、系统服务完全不受影响。

## 🛠 两种拦截模式

1. **DNS 拦截（可可端口）**
   - 域名库：内置精选原生列表（约 145 条）
   - 命中后：返回空解析，解析失败
   - 特点：轻快、兼容最稳

2. **规则拦截（可可 · 规则拦截）**
   - 域名库：国内专项 + 开源全量 **7 万条**
   - 命中后：返回 `0.0.0.0`，连接立即被拒绝
   - 特点：覆盖更全、拦截更快更彻底（推荐）

## 🧠 我们自己的三级匹配算法（防误拦）

不再像传统方案那样"单个关键字命中就拦"（那会误伤 `admin`、`adobe` 等正常域名），而是分层判断：

```
第①级 · 核心保护（最高优先，永不误拦）
   银行、支付、系统更新、主流 APP 主站（支付宝/微信/淘宝/抖音…）
   → 任何规则都拦不到它们

第②级 · 精确黑名单
   域名精确命中 7 万条内置库 → 拦

第③级 · 关键字匹配
   命中广告关键字 → 拦（核心已被第①级保护，不会误伤）
```

> 结果：广告照拦，扫码支付、系统更新、APP 主站等核心功能绝对安全。

## 📦 如何编译

环境要求：**Android SDK + JDK 17**（Android Studio 自带）。

```bash
# 克隆仓库
git clone https://github.com/vpn-user-demo/keke-adblock.git
cd keke-adblock

# 配置 SDK（二选一）：
#   1. 在项目根目录新建 local.properties，写入 sdk.dir=C:\\Users\\你\\Android\\Sdk
#   2. 或设置环境变量 ANDROID_HOME 指向你的 SDK 路径

# 编译 debug 版
./gradlew assembleDebug
```

APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。

> 💡 **国内加速**：如果下载 Gradle 太慢，把 `gradle/wrapper/gradle-wrapper.properties` 里的地址
> 换成 `https://mirrors.cloud.tencent.com/gradle/gradle-7.6.3-all.zip` 即可。
